# 2.2 Button Strip 

## Introduction

This example demonstrates how to interface a 5-key membrane button strip with the T-CORE-S3-24V development board.

The button strip consists of five individual push buttons:

1. Green Button
2. Yellow Button 1
3. Yellow Button 2
4. Yellow Button 3
5. Red Button

The example continuously monitors all button inputs and prints a message to the Serial Monitor whenever a button is pressed.

---

## What You Will Learn

By completing this example, you will learn how to:

- Read multiple digital inputs using the ESP32-S3.
- Configure GPIO pins using internal pull-up resistors.
- Detect button press events.
- Monitor button states through the Serial Monitor.

---

## Button Connections

Connect the membrane keypad as shown below:

| Button | ESP32-S3 GPIO |
|----------|-------------|
| Green | GPIO 4 |
| Yellow 1 | GPIO 5 |
| Yellow 2 | GPIO 6 |
| Yellow 3 | GPIO 7 |
| Red | GPIO 15 |

---

## How the Buttons Work

Each button is configured using the ESP32-S3's internal pull-up resistor.

| Button State | GPIO Reading |
|-------------|-------------|
| Released | HIGH |
| Pressed | LOW |

When a button is pressed, the corresponding GPIO pin is connected to GND, causing the input to read LOW.

## How to Run the Example

### Step 1: Open Arduino IDE

Launch the Arduino IDE and ensure the ESP32 board package is installed.

### Step 2: Select the Board

Navigate to:

```text
Tools → Board → ESP32 Arduino → ESP32S3 Dev Module
```

### Step 3: Select the COM Port

Connect the board to your computer using a USB Type-C cable.

Navigate to:

```text
Tools → Port → COMx
```

and select the COM port corresponding to your ESP32-S3 board.

### Step 4: Upload the Code

Copy the example code into a new Arduino sketch and click the **Upload** button.

Wait for the upload process to complete successfully.

### Step 5: Open Serial Monitor

Open the Serial Monitor and set the baud rate to:

```text
115200
```

### Step 6: Press the Buttons

Press any button on the membrane keypad and observe the corresponding message in the Serial Monitor.

## Arduino Code

```cpp
#define GREEN_BUTTON     4
#define YELLOW1_BUTTON   5
#define YELLOW2_BUTTON   6
#define YELLOW3_BUTTON   7
#define RED_BUTTON       15

void setup()
{
  Serial.begin(115200);

  pinMode(GREEN_BUTTON, INPUT_PULLUP);
  pinMode(YELLOW1_BUTTON, INPUT_PULLUP);
  pinMode(YELLOW2_BUTTON, INPUT_PULLUP);
  pinMode(YELLOW3_BUTTON, INPUT_PULLUP);
  pinMode(RED_BUTTON, INPUT_PULLUP);

  Serial.println();
  Serial.println("===== 5 KEY MEMBRANE KEYPAD TEST =====");
}

void loop()
{
  if (!digitalRead(GREEN_BUTTON))
  {
    Serial.println("GREEN BUTTON PRESSED");
    delay(200);
  }

  if (!digitalRead(YELLOW1_BUTTON))
  {
    Serial.println("YELLOW BUTTON - 1 PRESSED");
    delay(200);
  }

  if (!digitalRead(YELLOW2_BUTTON))
  {
    Serial.println("YELLOW BUTTON - 2 PRESSED");
    delay(200);
  }

  if (!digitalRead(YELLOW3_BUTTON))
  {
    Serial.println("YELLOW BUTTON - 3 PRESSED");
    delay(200);
  }

  if (!digitalRead(RED_BUTTON))
  {
    Serial.println("RED BUTTON PRESSED");
    delay(200);
  }
}
```
