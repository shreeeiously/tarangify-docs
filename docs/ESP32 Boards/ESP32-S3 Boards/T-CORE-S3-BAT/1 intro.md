# Tarangify T-CORE-S3-BAT

The **Tarangify T-CORE-S3-BAT** is a battery-powered ESP32-S3 development board designed for portable IoT devices, wireless sensor networks, environmental monitoring systems, and low-power embedded applications.

Built around the powerful **ESP32-S3-N16R8** module, the board combines wireless connectivity, onboard storage, battery charging, and battery monitoring features into a compact platform that is ideal for mobile and remote deployments.

Unlike conventional development boards that require external battery management circuits, the T-CORE-S3-BAT integrates battery support directly on the board, simplifying hardware design and reducing development time.

## Key Features

- ESP32-S3-N16R8 Microcontroller
- Dual-Core Xtensa LX7 Processor
- 16MB Flash Memory
- 8MB PSRAM
- Wi-Fi 802.11 b/g/n
- Bluetooth Low Energy (BLE 5.0)
- Li-ion / Li-Po Battery Support
- Integrated Battery Charging Circuit
- Battery Voltage Monitoring
- USB Type-C Programming and Charging
- Onboard microSD Card Slot
- WS2812B RGB LED (IO48)
- User Button (IO41)
- Reset and Boot Buttons
- 3.3V and 5V Output Rails
- 40+ Accessible GPIOs

## Why Choose T-CORE-S3-BAT?

Many portable IoT applications require battery operation, charging functionality, and battery monitoring.

Traditional ESP32 boards often require:

- External Battery Chargers
- Additional Battery Protection Circuits
- External Voltage Monitoring Hardware

The T-CORE-S3-BAT integrates these features directly into the board, providing a cleaner and more reliable solution for battery-powered development.

## Applications

The T-CORE-S3-BAT is ideal for:

- Portable IoT Devices
- Environmental Monitoring
- Wireless Sensor Networks
- Asset Tracking Systems
- Battery-Powered Data Loggers
- Smart Home Devices
- Remote Telemetry Systems
- Wearable Electronics

## Low-Power Development

The ESP32-S3 supports advanced power-saving modes, allowing applications to significantly reduce energy consumption when active processing is not required.

Combined with battery monitoring and charging support, the T-CORE-S3-BAT provides a complete platform for developing efficient, long-lasting embedded systems.

Whether you are building a wireless sensor node, a portable monitoring device, or a battery-powered smart product, the T-CORE-S3-BAT offers the flexibility and performance needed to accelerate development.
