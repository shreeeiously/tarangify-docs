# 1.1 RGB Strip 

## Introduction

This example demonstrates how to control an external WS2812 RGB LED strip using the T-CORE-S3 BAT development board.

The LED strip is connected to GPIO 4 and contains 51 individually addressable RGB LEDs. Each LED can display a different colour, allowing the creation of animations, indicators, and lighting effects.

In this example, the LED strip cycles through several solid colours before displaying a rainbow animation.

The following effects are demonstrated:

1. Red
2. Green
3. Blue
4. White
5. Off
6. Rainbow Animation

Each colour is displayed for one second before moving to the next effect.

---

## What You Will Learn

By completing this example, you will learn how to:

- Control a WS2812 RGB LED strip using an ESP32-S3.
- Use the Adafruit NeoPixel library.
- Display solid colours across an LED strip.
- Create a rainbow animation effect.
- Control multiple LEDs using a single GPIO pin.

## Wiring

| RGB Strip Pin | T-CORE-S3-BAT Pin |
|--------------|------------------|
| VCC | 5V |
| GND | GND |
| DIN | GPIO 4 |

> Ensure the LED strip has a suitable 5V power supply if a large number of LEDs are used.

## How to Run the Example

### Step 1: Open Arduino IDE

Launch the Arduino IDE and ensure the ESP32 board package is installed.

### Step 2: Select the Board

Navigate to:

```text
Tools → Board → ESP32 Arduino → ESP32S3 Dev Module
```

### Step 3: Select the COM Port

Connect the board to your computer using a USB Type-C cable.

Navigate to:

```text
Tools → Port → COMx
```

and select the COM port corresponding to your ESP32-S3 board.

### Step 4: Upload the Code

Copy the example code into a new Arduino sketch and click the **Upload** button.

Wait for the upload process to complete successfully.

### Step 5: Observe the LED Strip

After the code has been uploaded, the LED strip will begin displaying different colours and animations.

---

## Expected Behaviour

The RGB strip will:

- Turn **Red** for 1 second.
- Turn **Green** for 1 second.
- Turn **Blue** for 1 second.
- Turn **White** for 1 second.
- Turn **Off** for 1 second.
- Display a **Rainbow Animation**.

The sequence repeats continuously.

## Arduino Code

```cpp
#include <Adafruit_NeoPixel.h>

#define LED_STRIP_PIN   4
#define NUM_LEDS        51

Adafruit_NeoPixel strip(NUM_LEDS, LED_STRIP_PIN, NEO_GRB + NEO_KHZ800);

void setup()
{
  strip.begin();
  strip.show();
  strip.setBrightness(100);
}

void loop()
{
  setColor(255, 0, 0);
  delay(1000);

  setColor(0, 255, 0);
  delay(1000);

  setColor(0, 0, 255);
  delay(1000);

  setColor(255, 255, 255);
  delay(1000);

  setColor(0, 0, 0);
  delay(1000);

  rainbowCycle();
}

void setColor(int r, int g, int b)
{
  for (int i = 0; i < NUM_LEDS; i++)
  {
    strip.setPixelColor(i, strip.Color(r, g, b));
  }

  strip.show();
}

void rainbowCycle()
{
  for (long firstPixelHue = 0;
       firstPixelHue < 5 * 65536;
       firstPixelHue += 256)
  {
    for (int i = 0; i < strip.numPixels(); i++)
    {
      int pixelHue = firstPixelHue +
                     (i * 65536L / strip.numPixels());

      strip.setPixelColor(
        i,
        strip.gamma32(strip.ColorHSV(pixelHue))
      );
    }

    strip.show();
    delay(10);
  }
}
```
