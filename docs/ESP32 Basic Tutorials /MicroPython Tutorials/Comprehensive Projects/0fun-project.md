# Section 12: Comprehensive Projects

This section pulls together the GPIO, PWM, I2C/SPI, Wi-Fi, and BLE skills from earlier sections into complete, self-contained projects. Each one is a good next step for turning individual building blocks into something you'd actually want to build.

:::info

Make sure you've completed [**Section 1: Set Up Development Environment**](./1getting-started) through [**Section 11: Bluetooth**](./11bluetooth-communication) before starting these projects — each one draws on techniques covered earlier in the series.

:::

- **[Traffic Light](./1traffic-light)** — drives multiple LEDs through the timed sequencing logic of a real traffic signal.
- **[SOS Signal](./2sos)** — uses a buzzer and LED together to blink and beep out SOS in Morse code.
- **[Motion Sensor Light](./3presence-light)** — a PIR motion sensor triggers a WS2812 addressable LED strip.
- **[Fun LED Strip](./4led-strip)** — a potentiometer drives real-time color-changing effects on a WS2812 strip.
- **[Interactive Progress Bar](./5progress-bar)** — a potentiometer drives a live progress bar and gauge rendered on an OLED display.
- **[Internet Weather Display](./6weather-display)** — pulls live weather data over Wi-Fi from a weather API and shows it on an OLED display.
